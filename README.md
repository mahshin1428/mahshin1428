## Featured project

### [ChronoCTI](https://github.com/mahshin1428/ChronoCTI)
An NLP pipeline that reads cyber threat intelligence reports and extracts the **MITRE ATT&CK techniques** and **18 asset categories** they describe, each linked to its supporting sentence.

- CTI-adapted RoBERTa, Word2Vec, and spaCy classifiers, with 5 embedding setups compared across 5 data splits
- Temporal relations (NEXT / OVERLAP / CONCURRENT) between techniques, predicted with graph neural networks and XGBoost
- FastAPI + Angular app that visualizes the results as exportable graphs
